# Браслет намерения — Telegram Mini App

Прототип: персональный подбор камней для браслета намерения по таронумерологии
(имя, фамилия, дата рождения, намерение → 6–10 камней в порядке нанизывания).

## Файлы

- `index.html` — прототип, один файл. Подключён Telegram WebApp SDK, антикеш-мета,
  данные тянутся из `data.json`. При сбое загрузки показывает заглушку.
- `data.json` — справочники: камни с описаниями, соответствия арканам,
  пары усиления, словарь намерений, примеры заказов для истории.

## Расчёт (таронумерология)

Старшие арканы 1–22. Если сумма больше 22 — вычитаем 22, пока не станет ≤ 22.

- **Аркан судьбы** — сумма всех цифр даты рождения.
- **Аркан личности** — число дня рождения.
- **Аркан имени** — сумма букв имени и фамилии (алфавит 1–33).
- **Аркан намерения** — по ключевым словам текста запроса.

Камни подбираются по резонансу с этими арканами. Расчёт детерминированный:
одни и те же данные всегда дают один и тот же браслет.

## Публикация на GitHub Pages

1. Создать репозиторий на github.com (public), например `braslet-namereniya`.
2. Загрузить `index.html`, `data.json` (и этот README) в корень — через
   «Add file → Upload files» или `git push`.
3. Settings → Pages → Source: **Deploy from a branch**, branch `main`, папка `/ (root)` → Save.
4. Через 1–2 минуты появится ссылка `https://<логин>.github.io/braslet-namereniya/`.

## Подключение к боту

BotFather → `/newapp` (или `/myapps` → бот → Configure Mini App) →
Web App URL = ссылка с GitHub Pages.

## Обновление данных

Правишь `data.json`, коммитишь — Pages обновится сам. В приложении стоит
антикеш (`data.json?v=<время>`), поэтому свежие данные подтянутся сразу.
